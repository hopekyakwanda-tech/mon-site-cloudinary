# Hope Studio

## Description du projet

Hope Studio est un site vitrine simple et moderne qui met en avant des visuels de produits naturels et des bienfaits pour le corps humain. Le projet présente une page d'accueil, une galerie d'images et une page de contact.

## Objectif

Ce TP a pour but de :
- intégrer des images depuis Cloudinary ;
- concevoir un site responsive ;
- séparer les pages du site (Accueil, Galerie, Contact) ;
- présenter les coordonnées de contact de manière claire.

## Technologies utilisées

- HTML5
- CSS3
- Cloudinary
- GitHub

## Utilisation de Cloudinary

Les images du site sont chargées depuis Cloudinary via des URLs publiques. Cela permet :
- d'afficher rapidement les visuels ;
- d'utiliser des images externes facilement ;
- d'avoir une présentation plus professionnelle et moderne.

## Structure du projet

- `index.html` : page d'accueil
- `gallery.html` : page galerie
- `contact.html` : page contact
- `styles.css` : styles généraux du site

## Exécution locale

1. Ouvrir le dossier du projet.
2. Démarrer un serveur local :

```bash
python -m http.server 8000
```

3. Ouvrir dans le navigateur :

```text
http://localhost:8000/
```
